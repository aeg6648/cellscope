# CellScope (scaffold)

Side project: a battery-cell research helper for junior fast-charging engineers.

This scaffold only contains the local 1RC equivalent-circuit + lumped-thermal reference model (`cellscope/ecm.py`)
and its tests. The LLM pipeline (datasheet search, sandboxed simulation, explanation, safety screen) is being built on
the `hackathon` branch using the Otari gateway for the Mozilla Devs Wilding hackathon.
